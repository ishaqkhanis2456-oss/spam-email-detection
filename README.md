 Project Overview
This project classifies SMS/Emails as Spam or Ham (Not Spam) using Natural Language Processing.

Dataset: 5572 messages (4825 Ham, 747 Spam)
Accuracy: 98.29%

🛠️ Tech Stack
- Python
- Pandas, Scikit-learn
- NLP - CountVectorizer
- Algorithm - Multinomial Naive Bayes
